# Подборка успешных коротких дополнений

Отобранные примеры получены чекпоинтом `best` при temperature=0, seed=42, max_new_tokens=32. Ниже приведено первое короткое дополнение.

## Один плюс один

- **Один плюс один равно** → **два**

## Автор «Евгения Онегина»

- **Роман в стихах «Евгений Онегин» написал Александр** → **Пушкин**
- **Роман «Евгений Онегин» создал Александр** → **Пушкин**
- **Поэт, написавший «Евгения Онегина», — Александр** → **Пушкин**

## После зимы — весна

- **После зимы наступает** → **весна**
- **За зимой приходит** → **весна**
- **После холодной зимы к нам приходит** → **весна**
- **На смену зиме приходит** → **весна**
- **Зима прошла, и наступила** → **весна**

## После ночи — рассвет/утро/день

- **После ночи наступает** → **рассвет**
- **После долгой ночи приходит** → **рассвет**
- **Когда ночь уходит, наступает** → **рассвет**
- **После ночной темноты наступает** → **рассвет**
- **Ночь прошла. Теперь наступает** → **рассвет**
- **За ночью следует** → **рассвет**

## Зимой падает снег

- **Зимой с неба падает** → **снег**
- **Зимой с неба сыплется белый** → **снег**
- **В морозную погоду из облаков падает** → **снег**
- **Когда идёт снегопад, с неба падает** → **снег**
- **На улице зима, и с неба сыплет** → **ся снег**

## В дождь беру зонт

- **Когда идёт дождь, я беру с собой** → **зонт**
- **Если на улице дождь, я беру с собой** → **зонт**
- **На улице льёт дождь, поэтому мне нужен** → **зонт**
- **Идёт дождь. Перед выходом я возьму** → **свой зонт**

## Тише едешь — дальше будешь

- **Тише едешь — дальше** → **будешь**
- **Как говорится, тише едешь — дальше** → **будешь**
- **Не спеши: тише едешь — дальше** → **будешь**
- **Едешь тише — дальше** → **будешь**
- **Закончите пословицу: «Тише едешь — дальше** → **будешь»**
- **Есть пословица: тише едешь — дальше** → **будешь**
- **Народная мудрость гласит: тише едешь — дальше** → **будешь**

## Лучше поздно, чем никогда

- **Лучше поздно, чем** → **никогда**
- **Говорят: лучше поздно, чем** → **никогда**
